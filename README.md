# 灵枢录 · 校园成长记

发生在一所虚构工科学园的 React / TypeScript 文字养成游戏。八个学部对应不同研习方向，界面采用纸本校园风：成长档案、入学登记和校园手记。学校、人物与地点采用虚构设定。

![桌面主界面](doc/screenshots/桌面主界面.jpg)

## 当前状态

已完成存档与弹窗的增量模块化、历史 ESLint 诊断清理、主要界面的纸本设计和虚构校园设定。既有回归包括80种旧天赋组合和旧存档显示兼容检查。

普通冲刺、幸运事件、战斗奇遇、各类副本及社团挑战已统一接入逐轮操作。所有战斗先显示对手意图，再选择稳攻、防守或破势；可以撤离或自动应对一轮。六个预置机缘继续保留不同选项与后续，原商店和非战斗事件继续运行。现场保存后可刷新继续，终局统一结算一次；战斗期间冻结外部成长和回血。社团挑战胜利后才发任务奖励，一键交付只处理普通任务。详见[全场景战斗接入报告](doc/全场景战斗接入报告-2026-10-21.md)。

当前233项自动回归、类型检查与零警告代码检查通过；临时兼容参数构建通过。标准构建仍有环境路径权限错误，浏览器连接本地预览超时，真实布局与多标签存档锁尚未验收。详细边界和日志位置见上述报告。

AI 接入基础已有初步实现：三种协议、13类接入预设、三项游戏内文案技能、集中提示词及异常输出校验。AI只润色程序已经确定的结果，默认关闭。上述六机缘由本地规则与预置文本运行，没有新增模型内容技能；模型生成分支、长项目与持久人物记忆仍待实现，道具和室友战斗支援暂缓。AI基础检查结果与当时的构建限制见[初步实现报告](doc/ai/初步实现报告-2026-10-16.md)。真实AI接入尚未完成验收。

后续独立自测修复了重复点击结算、未完成响应误判、配置异常显示和旧天赋叙事误判。122项自动化与5项本机HTTP检查通过，具体证据及未验收边界见[自测与修复报告](doc/ai/自测与修复报告-2026-10-16.md)。

**数值审计发现31项主要问题（7项优先处理），尚未修复。** 包括升级丢失部分加成、一键消耗和强化结算不一致、抽奖保底/奖励数量错误，以及室友战力未接入战斗。请先阅读[数值审计报告](doc/数值审计报告-2026-10-15.md)，不要将“回归通过”理解为数值系统已正确。

## 本地运行

需要 Node.js 22 与 npm。

```bash
npm ci
npm run dev
```

默认端口3000，已占用时由Vite选择下一个端口。游戏进度保存在当前浏览器，换浏览器或站点不会自动同步。互动机缘需要支持 Web Locks 的现代浏览器，在 localhost 或 HTTPS 页面使用；同一存档只允许一个游戏标签页写入。旧存档仍可导入，但旧客户端可能丢失互动扩展，不能保证降级后继续现场。AI默认关闭，使用本地模板。排行榜/UID后端与真实AI接口未做本轮集成验收。

## 检查与审计

```bash
npm test
npm run test:ai:http
npm run typecheck
npm run lint -- --max-warnings 0
npm run build
node scripts/numerical-audit/run.mjs . ./audit-output
```

审计脚本用固定时钟与随机数直接观测生产函数，不读取真实玩家存档，不请求网络。诊断输出包含已知缺陷，脚本完成不代表数值健康。

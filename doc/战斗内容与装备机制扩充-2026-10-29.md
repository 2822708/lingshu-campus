# 战斗内容与装备机制扩充

完成日期：2026-10-29。范围：正式卡牌副本、主背包与装备说明。已在本地接入，可从“考研副本 → 整理简历”使用；未提交、上传或部署。

## 体验设计与实现

沿用每回合3专注、抽4张、保留手牌、超10张手动弃牌和12回合上限。通过对手节奏、装备特性与少量可选卡牌形成不同打法，继续使用单行4:3横牌、悬停查看和铺满窗口的布局。

### 六种对手特点

| 对手特点 | 实际行为 | 应对方式 |
| --- | --- | --- |
| 追问辩手 | 试探 → 集中追问 → 调整 | 预留防护迎接第二轮，调整轮组织输出 |
| 论证守门人 | 固守两轮 → 交叉检查 → 核心质疑 | 先破势，减少固守造成的输出损失 |
| 抢答快手 | 首轮快攻含20%穿透 → 连续发问 → 换气 | 兼顾进攻与精力，防护只能抵挡非穿透部分 |
| 干扰考官 | 低威力50%穿透 → 强攻30%穿透 → 普通来袭 | 观察实际穿透量，避免完全依赖堆防 |
| 漏洞聚合体 | 每三轮尝试修复精力上限的4% | 抓住修复前的击破机会，避免长期空转 |
| 反问评审 | 首轮固守并反震 → 追究细节 → 倾听 | 破势可同时移除固守与反震；致命进攻不触发反震 |

这些特点附加在原游戏分级产生的敌人上，原姓名、学阶、攻击、防御、手速、精力、风险与掉落计划保留。敌人纸偶各有相应小图形。当前行动、穿透、修复、反震及预计损失在同一战斗区展示，完整三步循环可在“规则”查看。敌型在入场时确定，行动循环随现场保存。

### 六张可选战术牌

| 卡牌 | 专注 | 作用与取舍 |
| --- | ---: | --- |
| 试探落点 | 1 | 抽1张并施加一次破绽，下次进攻威力增加25% |
| 防守反问 | 1 | 获得防护，本轮挡住来袭且存活后反击 |
| 留有余地 | 1 | 获得防护，保留一定未消耗防护到下一回合 |
| 转守为攻 | 1 | 消耗当前全部防护，把其中50%转为追加进攻，追加有上限 |
| 重整节奏 | 0 | 恢复1专注，上限3，本场一次 |
| 审题标记 | 0 | 施加一次破绽，本场一次 |

默认基础简历仍为8张。战术牌在“可用来源”中可自行加入牌库，再选入8–16张简历；可以从牌库移除。破绽不叠层，只影响下一次主动进攻。反击每轮结算一次，累计的反击威力与装备反击一并结算；反击不触发对手反震。留盾只保留尚未被消耗的防护。

机制产生的伤害、防护、反击与转攻上限均在入场时按原角色和敌人预算换算。百分比与专注不会随学阶膨胀；治疗继续不超过入场精力。

| 青轴机械键盘 | 每回合首次进攻追加较多威力 |
| 军训迷彩服 | 开场获得防护 |
| 静音红轴键盘 | 开场额外抽1张 |

| 运动护腕 | 挡伤且存活时追加反击，每轮一次 |

另为新增支持的六件装备提供装备牌，包括抽牌回专注、破绽、破势抽牌、留盾与防守反击。装备特性和装备牌相互独立：真实穿戴即可获得被动，想使用对应主动牌还需选入简历。基础属性只使用角色已经计算完成的最终值，不把装备面板属性重复相加。

主背包、装备栏、简历准备和战斗内“装备”笔记均可查看特性。来源按真实库存实例、穿戴槽位、类型和数量检查；同一物品ID重复挂在多个槽位也只计算一次。

## 可尝试的配合

- **破绽进攻**：审题标记 → 直击要点；对反问评审先解除固守与反震，再组织进攻。
- **防守反击**：工牌首次防御加成 → 防守反问 → 护腕反击；手环或散热底座留下多余防护。
- **转守为攻**：提前积累留盾，下一轮用转守为攻输出；留意防护被消耗后上升的预计损失。
- **节奏调整**：在已经消耗专注时使用重整节奏；静音换挡可抽牌并返还其专注消耗，均为本场一次。

牌多会稀释关键进攻牌。建议先替换2–3张基础牌尝试一种配合，再按敌人特点调整。

## 兼容与模块边界

- `features/card-battle/engine.ts` 负责机制、冻结行动循环、装备触发、预览和纯指令转移，不读浏览器存储、不发主游戏奖励。
- `enemies.ts` 管理敌型与循环；`catalog.ts` 集中卡牌定义。旧独立试玩奖励池排除新增战术牌，避免抽到尚未支持的机制；原22张模板玩法不变。
- `features/card-dungeon/equipment.ts` 是装备特性与装备牌映射的单一来源；`budgets.ts` 供装备与卡牌共用，原数值适配导出路径兼容。
- 主互动层仅在新入场时解析新敌型与装备。旧现场缺少新增字段时仍继续旧随机节奏，不重新抽敌人或装备效果。
- 不提高存档外层版本。新版读取旧现场已检查；不保证旧客户端能读取带新卡牌与机制的现场。
- 修复了读档用用途描述覆盖合法外设、手环、挂件槽位的问题。例如运动护腕描述包含“敲键盘”，现在不会因此被改成键鼠。原有裤装等错槽修复仍保留。
- 普通冲刺、社团及旧逐轮战斗继续原系统，本次装备特性的生效范围明确标为“卡牌副本”。

## 检查与试玩

最终常规检查 **429/429通过**，包括机制结算、预览、反击终局、反震死亡、穿透、修复、真实装备来源、可选战术交互、导出续档、重复指令和旧现场兼容。类型检查、相关代码ESLint、正式游戏与独立试玩构建通过。

使用独立3048端口及测试存档，在浏览器中实际完成：

- 标记破绽、工牌首次防御加成、护腕追加反击、手环与散热底座留盾，随后刷新续战。
- 初始防护6 → 防守反问及工牌增加8 → 挡住3 → 反击11 → 留盾8，显示与实际一致。
- 抢答快手来袭5，其中穿透1、防护抵挡4；实际精力140→139。
- 转守为攻消耗原有6防护并命中12；漏洞聚合体随后修复1，精力18→19。
- 主背包及实际穿戴栏显示护腕特性；准备页展开六件穿戴特性、移出可选战术牌并保存13张简历。
- 1280×720与320×480布局、键盘出牌及牌文案；窄屏反震和破绽同时显示时，无横向溢出，主按钮下缘475.5px。保存失败时提示高32px，专注、精力与手牌未消耗。

敌人反击和修复同轮发生时，会分别反馈损耗与恢复，避免精力净变化掩盖实际动作。拥挤手牌的浏览器操作采用可见边缘或键盘选择，未把被其他牌遮住的几何中心当作玩家点击位置。

### 固定种子数值抽查

七个学阶5级、四风险、六敌型、三构筑、每格3个种子，共 **1,512场**。测试策略仅读取当前手牌、公开简历和已公布行动，每一步验证现场结构。装备构筑保持最终角色属性相同，仅比较特性带来的作用。

| 风险 | 基础8张 | 加六件装备特性 | 同装备并加入全部六张战术 |
| --- | ---: | ---: | ---: |
| 低 | 100% | 100% | 100% |
| 中 | 66.7% | 88.1% | 85.7% |
| 高 | 7.9% | 28.6% | 11.1% |
| 极度危险 | 0% | 0% | 0% |

这组结果说明装备有实际作用，盲目塞满战术会增加高风险僵局；原成长与风险门槛仍存在。样本与自动策略有明确局限，不代表所有构筑平衡或真人试玩结论。

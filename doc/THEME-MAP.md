# 主题词表 · 虚构工科学园

本项目由 `react-xiuxian-game` fork 而来，当前产品名为《灵枢录 · 校园成长记》，故事发生在一所虚构的工科学园。
**改任何文案前先查这张表**，保证全局用词一致。

## 当前设定与文案边界

品牌、欢迎语和 AI 背景以 `config/campusTheme.ts` 为统一来源。学校、学部、社团、人物与地点均为虚构，不对应现实学校，不引用现实校训或机构背书。地点采用东区、西区、图书馆、研习室、实训室等通用称呼。

页脚使用“一页日常，一点成长”，档案短句使用“学习 · 实践 · 记录 · 成长”。保留学习、实验、社团、宿舍与工程实践的校园氛围；C、Java、PCB、FPGA、Linux、CTF 等正常技术与学科词汇可以继续使用，不以消除现实学校关联为由泛化替换技术术语。

专业方向统一为以下 8 个虚构学部，现有方向 ID 与效果不变：

| 方向 ID | 学部 | 专业灵根 |
|---|---|---|
| `circuit` | 电路学部 | 电路灵根 |
| `signal` | 信号学部 | 信号灵根 |
| `algorithm` | 算法学部 | 算法灵根 |
| `network` | 网络学部 | 网络灵根 |
| `optoelectronic` | 光电学部 | 光电灵根 |
| `iot` | 物联学部 | 物联网灵根 |
| `material` | 材料学部 | 材料灵根 |
| `automation` | 自控学部 | 自动化灵根 |

## 八、功法（CultivationArt）

- `type: 'mental'`（心法）→ **编程语言 / 理论课**，主加绩点效率
- `type: 'body'`（体术）→ **硬件实操 / 工程能力**，主加属性

命名参考：C 语言基础、Python 速成、数据结构、信号与系统、模电实验、Linux 内核、机器学习……

## 九、室友（原灵宠）

灵宠 / 灵兽 → **室友**。种类用室友人设：卷王室友、电竞室友、考研室友、创业室友……
亲密度 → **默契度**，进化 → **成长**。

## 十二、旧命名空间与文案兼容

此次调整只统一背景和展示文案，不修改存档版本、数值、概率、奖励、领域枚举或模块接口。下列历史标识继续保留，其存在不表示当前产品仍关联现实学校：

- 天赋 ID 使用 `npu:<方向ID>:<命格ID>`，继续由 `npu-data.ts` 解析；不要为展示改名而重写 ID 或文件名。
- 浏览器存储键 `npu-game-save`、`npu-game-settings`、`npu-user-ai-config` 保持不变，避免丢失现有进度、设置和本地 AI 配置。
- CSS 中的 `npu-` 前缀属于现有样式接口，保持不变；仓库名、历史发布链接和代码路径保留可追溯性。
- `utils/campusText.ts` 只对已知旧学校文案作展示适配。历史手记与物品原始文本仍可存在于旧存档，导出的原始档案也可能保留旧词；不要因此清空旧档或擅改原始日志。
- 玩家姓名不应用主题替换；物品的业务名称键、配方键、ID、装备关联与数值不能被批量文本替换。必要时仅在 JSX 展示处转换物品名称与描述。
- AI 的事件、升学和对手名称生成均使用虚构背景；生成文案的适配不应触碰结构化 ID 或数值字段。

`PLAN.md` 保留早期策划的结构与数值，不代表全部功能已经实现。历史工作报告、审计数据、更新记录和旧截图按当时证据保留；当前说明与新预览以本文件及主题配置为准。

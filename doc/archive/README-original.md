## 📖 项目简介

《灵枢录——南邮修仙传》是一款以**南京邮电大学（NPU）校园生活**为蓝本的现代修仙文字冒险游戏。玩家扮演一名 2025 级南邮新生，以"专业灵根"踏入修真之途，在 4 年（游戏时间）内从大一新生修炼到飞升成仙。

游戏将工科元素（编程语言、外设法宝、算法心法）与修仙机制（境界突破、五行克制、炼丹炼器）巧妙融合，同时融入大量南邮校园梗（仙林/三牌楼、麻辣香锅、食堂断网、深夜调 Bug 等），打造一款**理工科专属的修仙模拟器**。

完整策划案见 [`PLAN.md`](./PLAN.md)。

## 🎮 游戏玩法

### 基础操作

#### 1️⃣ 创建角色
1. 选择你的**学院**（决定专业灵根）
2. 抽取随机**命格**（卷王命/摆子命/欧皇命等）
3. 命名你的角色，开始修仙之旅

#### 2️⃣ 修炼突破
- **上课**：被动吸收灵气
- **自习 / 图书馆 / 实验室**：主动修炼，效率×1.5-3
- **通宵**：效率×4，但白天 -50%
- **顿悟**：随机触发，效率×5-10

当修为达到上限时，可尝试**突破境界**——突破成功大幅提升属性，失败会损失部分修为。

#### 3️⃣ 挑战秘境
- **期末高数**、**四六级**、**大创答辩**、**电子设计竞赛**、**ACM 校赛**、**考研初试**、**毕业答辩**、**求职面试**、**CTF 夺旗赛**、**挑战杯**……

#### 4️⃣ 装备养成
- 收集外设法宝，强化升级
- 选择"本命法宝"获得 50% 属性加成

#### 5️⃣ 灵宠养成
- 招募室友（卷王、摆子、欧皇、肝帝……）
- 培养好感度，解锁室友天赋

#### 6️⃣ 炼丹炼器
- 收集材料，炼制咖啡/奶茶/能量饮料
- 使用丹方解锁更多配方

#### 7️⃣ 宗门任务
- 加入社团，完成日常/周常/月度任务
- 提升贡献度，解锁宗门商店

## 🚀 快速开始

### 环境要求

- **Node.js** >= 18.0.0
- **pnpm** >= 8.0.0（推荐）或 **npm** >= 9.0.0

### 安装步骤

```bash
# 1️⃣ 克隆项目
git clone <your-repo-url>
cd xiuxian-npu

# 2️⃣ 安装依赖
pnpm install
# 或 npm install

# 3️⃣ 配置环境变量（可选，仅当需要 AI 动态事件时）
cp .env.example .env.local
# 编辑 .env.local，填入 API Key

# 4️⃣ 启动开发服务器
pnpm dev
# 或 npm run dev
```

打开浏览器访问 `http://localhost:3000`，开始你的南邮修仙之旅。

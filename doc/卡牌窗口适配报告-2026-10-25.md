# 卡牌窗口适配报告

日期：2026 年 10 月 25 日。根据“确保整个页面在浏览器内完整显示”的要求，调整独立试玩《课后演练》的布局。当前试玩页已更新，原有进度继续保留。

## 改动

- 增加 `viewport.css`，页面根据浏览器可用高度分配页头、进度、战斗、反馈、手牌、档案入口和底部操作；不使用全页缩放或隐藏溢出裁掉内容。
- 常规桌面四张基础手牌同排完整显示。更多手牌和窄屏采用手牌区局部横向滚动，支持键盘聚焦自动滚入视野；低矮窗口的长文本在所属区域内滚动。
- 牌组、回合记录和规则改为点开面板，内容在窗口内滚动。返回牌桌按钮和 Escape 均可收起，并把焦点放回入口。
- 保存错误和重开确认使用窗口内提示层。最近反馈聚焦当前已保存指令的结果，完整历史仍可查看。
- 删除换场时把整页滚到标题的行为，保留标题焦点引导。修正顶部外边距塌陷造成的额外页面滚动。

仅修改独立原型展示层。未改主游戏、引擎、卡牌数值或持久化协议；未创建 Git 提交、上传或部署。

## 实际浏览器验收

使用应用内浏览器测试 5 种局面：基础四手牌、八手牌、胜利选牌、通关结果、欢迎页。各自检查下列 7 种视口，共 35 组：

| 视口宽 × 高 | 页面超出窗口 | 底部操作超出窗口 |
| ----------- | ------------ | ---------------- |
| 1366 × 768  | 无           | 无               |
| 1265 × 712  | 无           | 无               |
| 997 × 764   | 无           | 无               |
| 1024 × 600  | 无           | 无               |
| 390 × 844   | 无           | 无               |
| 320 × 568   | 无           | 无               |
| 844 × 390   | 无           | 无               |

通过 DOM 实测比较页面滚动尺寸与视口尺寸，并检查结束回合、档案入口和底部操作的位置。所有 35 组均无整页横向或纵向溢出；高度超过 520 的受测窗口，卡牌自身也没有纵向内容溢出。窄屏与八手牌局面仍需在手牌区内横向查看全部卡牌；低矮横屏允许战斗信息及卡牌文本局部滚动。

额外实际检查：

- 窄屏下用键盘聚焦最后一张牌，手牌区自动滚至该牌，整页没有滚动。
- 回合记录面板可通过 Escape 收起并回焦；重开确认与保存错误提示均完整处于窗口内。
- 320 × 568 欢迎页中，开始试炼按钮和输入框完整可见，长规则独立滚动。
- 恢复用户默认窗口后实际视口为 1012 × 764，页面尺寸同为 1012 × 764；原有第 2 场、第 5 回合现场继续显示。真实 38 条回合记录在面板内滚动，没有撑高牌桌。

测试局面使用单独的内存存储，没有操作用户真实试炼的出牌、结束回合、选牌或重开。临时验收入口已移除，副本与测量结果保存在本会话 `outputs/卡牌窗口适配-2026-10-25/`，包括 `fit-matrix-final.json`、桌面/窄屏截图及真实用户窗口截图。浏览器视口模拟不代表真实手机设备或所有浏览器均已验收，也不是本轮动画时序的专项验收。

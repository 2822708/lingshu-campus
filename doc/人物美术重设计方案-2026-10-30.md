## 现有造型的问题

- 当前桌面全身立绘在约134px高的区域内显示，脸部只占十几像素；肩、手、腿都很小，增加鼻眼线条也难以改善观感。
- 玩家和对手的站姿、脸型、头发和衣服接近，像同一个模板换了配件；缺少能一眼认出的性格与身份。
- 肩颈、肘部和手势偏僵硬；灰绿细线与浅填色的明暗差小，看起来像图标或教辅插画，人物缺乏体积与情绪。
- 过去从圆头改成人体比例，解决的是低幼比例问题，并未完成好看的人物设计。审美不能以SVG变复杂、细线更多或通过测试作为完成依据。

## 推荐人物规范

### 构图与年龄感

- 正常窗口使用腰部以上或略到大腿的三分之二侧身立绘；玩家朝右，对手朝左，视线朝向对方。避免两人正对屏幕笔直站立。
- 常见学生角色呈现18–25岁的青年年龄感，穿休闲外套、针织衫、衬衫、T恤和背包；不同身份再采用差异化服饰。
- 通过眉眼、下颌、鼻形、发型和肩背姿态区别角色，不只改变颜色。眼睛、头身比例自然，减少幼态和夸张装饰。
- 主角拿笔或笔记本的动作应能表达思考、准备和反驳；对手用抱资料、前倾发问、交叉手臂等不同姿态形成对峙。

### 颜色与绘制

- 页面沿用当前纸白；人物轮廓用深墨色，阴影用明确的大色块，保留自然肤色。
- 主角以墨绿/藏蓝与米白为主；对手根据身份加入赭红、烟灰或土黄，使双方有区别而不过分鲜艳。
- 纹理以少量纸感和干笔为主，不能遮住五官、手指与外轮廓。人物本体和页面背景分离，避免叠加后出现一块明显的米色矩形。
- 人物道具保留通用校园元素，不带现实学校名称、校徽、校训或商业品牌。

### 页面中的显示

- 优先在现有立绘区域内改变裁切和占比，使脸和手势更大；不以不断增加人物高度挤占卡牌和操作区。
- 普通桌面以人脸宽约28–40px作为设计目标，在实际界面中检验。它是可读性目标，不是所有矮窗口都能保证的固定数值。
- 窄矮窗口改为胸像裁切，保留脸、肩和一个关键手势，避免把全身继续缩成细小人影。裁切点要自然，不截断下颌或重要手势。
- 人物与血条继续上下排列；状态与敌方意图保留在战斗区域内，不能因换素材重新出现独立右上行动板或“刚刚”整行。
- 卡牌继续保持**高:宽4:3**、单行和当前悬停/聚焦规则；角色装饰与动效避开手牌及底部按钮。

## 对手辨识方案

先用轮廓与动作区分，再用配色辅助。以下是对现有六类的美术表达，沿用现有战斗机制和数值。

| 现有类型   | 主轮廓与姿态                 | 识别道具/气质                                                              |
| ---------- | ---------------------------- | -------------------------------------------------------------------------- |
| 追问辩手   | 修长、略前倾，抬笔发问       | 小笔记本与清晰的指向手势，专注而主动                                       |
| 论证守门人 | 较宽且稳的轮廓，抱紧厚资料   | 闭合姿态、大资料夹，强调固守感                                             |
| 抢答快手   | 轻便衣着、卷袖，动作打开     | 资料较少，抬手迅速，强调先手压迫                                           |
| 干扰考官   | 明显的侧身与不对称手势       | 展开的便签或标注页，视觉节奏打散                                           |
| 漏洞聚合体 | 唯一可探索的半抽象轮廓       | 层叠错题页、擦改痕和影子形成不稳定的体块，保持成熟纸本风格；不采用笑脸纸怪 |
| 反问评审   | 紧凑轮廓，交叉手臂或手抵下颌 | 犀利的侧向目光和少量资料，强调等待反问                                     |

首轮不必同时定死所有人的脸型和服饰。应先完成差异最大的三个人物并实际比较，避免形成六个近似脸的变体。

## 动作反馈

继续采用易实现的短动作，围绕现有真实结算播放：

- 出手：人物向内轻微前移并倾身，笔迹或短线扫过对手一侧。
- 受击：短促后移、回弹，清晰的实际伤害浮字；保持脸部可辨认。
- 防护：身前短暂出现纸张/墨线弧形，配合真实抵消量。
- 恢复和奖励：颜色与数值变化明确，避免人物与整页同时闪烁。

首版每角色一张主体立绘配合已有位移、回弹和浮字即可。表情确有需要时再增加专注/受击等少量变体，暂不引入复杂骨骼动画或新的操作步骤。

## 制作与实施顺序

1. **风格确认，已完成**：用户选择C套色版画。对比稿和三角色稿作为方向参考，不作为最终切图直接上线。
2. **最小样稿**：主角、追问辩手、论证守门人各一张独立半身立绘，统一光源、轮廓和纹理。以约768×1024透明PNG作为源素材；导出尺寸按真实显示与清晰度确定。
3. **真实页面验证**：只替换本地预览中的人物图层，检查普通、窄屏和矮屏的脸部/轮廓可读性及动效边界。
4. **统一扩展**：样稿通过后再扩展其余类型和必要表情。素材由统一清单按现有敌人类型选择，缺失素材有一致的替代形象。
5. **实施验证**：保留当前结算和保存后触发的动效行为，检查刷新、胜负、破防及减少动态效果设置，最后再交给专门上线的对话发布。

本轮只输出方案；不替换当前人物，不操作部署中的生产版本。

## 验收标准

- 在真实战斗页面上能够看清眼神、表情和一个关键动作，不能只在原图放大时好看。
- 只看剪影仍能分出主角、稳守对手和快攻对手；两人不能只是左右镜像。
- 几名角色放在一起时，肤色、轮廓、笔触与光线一致，服饰/脸型/姿态有明显差别。
- 缩至实际尺寸及转为灰度后，人物仍与背景有清楚层次；血条、威胁预告与手牌不被人物或特效遮挡。
- 不破坏卡牌比例、单行手牌、人物与血条分行及窗口内操作完整显示等既有要求。
- 通过实际页面观感确认，再做资产完整性、运行和旧档兼容检查；测试通过不能替代美术验收。

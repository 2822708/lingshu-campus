# 工科校园修仙主题回归方案

本方案形成于2026-10-31。2026-11-08已完成本地实施与验收。[实施记录](工科校园修仙主题回归实施记录-2026-11-08.md)

## 核心定位

玩家是一名在虚构工科学园修行的学生：学习课程以领悟术式，开展实验以炼制法器，通过课题与试炼完成突破。校园生活提供人物、地点和成长阶段，工程方法决定战斗中的选择，修仙提供力量表现与突破的期待。

去除现实学校元素的范围继续保持。课程、工程术语、原创修炼设定与校园身份应当保留。纸本校园是界面的表现方式，内容仍需呈现修习、炼器、同门与渡劫。

校园成长与独立肉鸽共享世界观。前者记录长期校园修行，后者是一场压缩的“灵枢试炼”，独立保存本局精力、试炼学分、术式与法器。主游戏已有学阶和存档结构暂沿用，试炼章节不意味着修改主游戏境界。

## 当前偏离及原因

- 入口把校园生活与远征手记分成两种叙事，职业没有学生身份和学科来源。
- `course-code`、`course-math`、`gear-keyboard` 等来源牌被重新命名为推演线索、洞悉核心、快刃，课程与装备的关联在展示中消失。
- 猎牙、龟甲片、青铜肩甲、旅人披风与裂隙游猎者等内容缺少工科学园里的取得原因。
- “沿途补给、搬运物资、请旅人整理牌组”没有同学、研习室、工坊和课题情境。
- 早期主题词表把修仙全面替换成普通学习成长，削弱了原主题特色。

修正应先回答“我是谁、为何参加、卡牌从何学来、装备为何有效、通关代表什么”。名称、美术与反馈随这些关系一起调整。

## 内容关系与机制对应

以下为候选设计，不代表已实装新系统。优先使用现有抽牌、蓄势、破绽、防护、留盾、反击与转攻能力，不另加资源条。

| 内容     | 回归方向                               | 已有机制如何承载                                             |
| -------- | -------------------------------------- | ------------------------------------------------------------ |
| 进攻职业 | 机巧器修，工坊实践的学生               | 连击、蓄势和装备强化后的爆发                                 |
| 防御职业 | 电路阵修，研究电路与控制的学生         | 电容储能对应留盾，负反馈对应防护反击                         |
| 调度职业 | 符算修士，研习算法与信号的学生         | 仿真推演对应抽牌，误差分析对应破绽，调度对应恢复专注         |
| 课程牌   | 课程方法形成可执行术式                 | 仿真推演、故障定位、储能释放各自保留明确的行动效果           |
| 法器     | 实验制作、工坊改造或课题所得器材       | 示波镜开场多抽一张，储能模组保留防护，防静电腕带提供入场防护 |
| 普通敌人 | 试炼傀儡、失控机巧、噪声幻象与课题心魔 | 公开行动表现过载、校准、穿透、冷却和修复                     |
| 休整     | 研习室调息与复盘                       | 恢复精力、参悟升级或整理移除术式，保持三选一                 |
| 商店     | 工坊与资料室服务                       | 使用本局试炼学分治疗、改造术式、取得法器                     |
| 事件     | 助研、实验机会、同门交流与器材故障     | 使用现有稳定补给、付出精力换收益、付费删牌的代价结构         |
| 战后奖励 | 课程领悟、实验成果与考核报酬           | 三选一术式或跳过，精英与章节奖励增加法器选择                 |

例：电路阵修先用“电容护阵”积存防护，再用“储能释放”把防护转成进攻；遇到穿透型噪声幻象时，需要通过“故障定位”发现破绽并尽快击破。工程概念对应真实的决策差异，牌面说明始终保留可读的精确效果。

独立模式可使用“精力、专注、试炼学分、术式牌组、法器”等词。回合、抽牌、弃牌等操作词保持清晰。课程序列和装备来源通过简短标签展示，不用额外中间选择页增加操作负担。

## 五章与BOSS的统一目标

保留50个混合节点、每10节点一个BOSS。五章表现同一次试境内的修习层次，节点类型与已有指令不因主题修改而改变。

| 章节  | 主题       | BOSS候选与原有考验                                     |
| ----- | ---------- | ------------------------------------------------------ |
| 1–10  | 基础课筑基 | 高数心魔：蓄力、压轴重击、推导间隙，检验出牌与防护时机 |
| 11–20 | 实验炼器   | 失控谐振阵：固守与反震，检验破防和反馈回路的应对       |
| 21–30 | 竞赛论道   | 噪声灵障：穿透来袭，检验进攻与精力资源的取舍           |
| 31–40 | 课题攻关   | 自修复灵傀：不断修复、维护窗口，检验集中爆发           |
| 41–50 | 结业渡劫   | 答辩天劫：综合行动循环，检验整套构筑                   |

每次奖励都说明取得原因：解决故障获得实验成果，完成考核领取试炼学分，击败章节BOSS领悟新术式。普通同学、导师可以担任交流者或切磋考官，主要敌对表现由心魔、幻象和失控器械承担。

## 视觉与实施顺序

保留纸本校园、成熟角色比例、C套色版画、高:宽4:3单行卡牌、人物与血条分离，以及公开敌人意图。场景使用研习室、实训台、图书馆、社团工坊与试炼阵；角色采用校园穿着、实验护具和原创学部纹样，工程术式通过电路阵纹、波形、符算草稿表达。

1. 统一入口定位、世界观和术语，修正两模式的关系及新手引导。
2. 按机制逐一重写3职业、6套初始牌组、34张卡、18件法器与5位BOSS，补齐课程/器材来源和成长原因。
3. 给事件、商店、休整及奖励增加同一校园场景中的因果，检查选择前代价和选择后反馈。
4. 更新人物与战场资源、旧档展示兼容和相关检查，完成完整一章的浏览器试玩后再扩充内容。

验收时，每个新内容至少能说明一项具体工科学科/校园生活来源、一项修仙表达和一项实际玩法作用。对于抽象的通用基础牌，可以由所属课程和场景提供背景，不要求每个名字堆叠三种标签。

主题替换沿用稳定ID和冻结快照。保存内容可在继续游玩时恢复，显示文案由主题映射提供。

# 公开发布说明

日期：2026-10-15。目标：2822708/xiuxian-npu（公开）。

本次发布包含当前模块维护、纸本校园界面和数值审计成果，不包含31项数值问题的修复。原本机审计基线为872b225，公开仓库使用独立脱敏历史；旧历史、旧dist和旧bundle曾可能包含API密钥，因此仅保留在本机，没有上传。

生产环境文件、任何非空API密钥、真实玩家存档、server/data、node_modules均不发布。环境模板只有公开选项。网页构建从无密钥副本重新生成，未沿用旧构建产物。

发布包：源码ZIP、网页ZIP、审计ZIP、独立脱敏Git快照bundle与SHA256SUMS。所有下载包仅从此脱敏副本生成。Git快照不是原本机完整提交历史；它可恢复本次公开版本。

原19项测试用于维持历史行为。数值审计的53组作用矩阵、169个显式number声明字段、80种学院命格组合、63档成长、14个配方和99个抽奖项另有原始证据。真实AI、UID/排行榜后端、设备与上线部署仍需独立验证。

审计文档中保留的本机提交编号用于追溯审计时间点，不表示公开仓库拥有相同提交对象。

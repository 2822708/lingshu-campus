# 0002 纸本校园界面

状态：已采用。日期：2026 年 10 月 15 日。

## 背景

用户认为现有 UI 的 AI 痕迹过重，并明确选择“纸本校园风，像课程表和成长档案”。这项后续授权替代 ADR 0001 中本轮不改界面的约束；玩法、数值、存档和业务模块边界继续遵守原决策。

## 决策

首页采用成长档案封页，建角采用入学登记表，主界面由学籍档案、校园手记和今日行动组成。使用暖白纸色、墨绿强调、宋体标题、系统中文正文字体、细分隔线与自然文案；取消终端提示符、大片发光与渐变装饰。图片和字体不增加远程依赖。

全局颜色由 `index.css` 中的 CSS 变量定义，Tailwind 的 npu 颜色映射这些变量。`styles/entry.css` 管理入口页面，`styles/navigation.css` 管理页眉、操作与手机目录，`styles/journal.css` 管理档案与手记；组件保留展示职责。旧弹窗继续使用现有布局，通过主题和浅色按钮适配；背包工具栏另做手机拆行。

桌面档案与手记并列，手机主界面将档案收进目录，主操作保持普通 flex 文档流，日志占据剩余高度。菜单和移动档案支持键盘聚焦、Escape 关闭和焦点返回；系统减少动态效果偏好获得尊重。保留所有已有操作回调、一次命格重抽限制、日志分页与自动滚动。

## 影响

这次只调整展示及导航交互，不修改游戏规则、领域服务、存档字段或依赖版本。已有功能弹窗完成色彩兼容，但未逐个重做内部信息结构。后续新增 UI 应先复用上述变量与样式分区，避免重新引入大面积深色、发光、营销式卡片或终端语气。

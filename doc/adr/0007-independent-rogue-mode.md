# 0007：独立肉鸽模式与校园成长互斥挂载

状态：已实施于本地，2026-10-31。

用户要求在进入游戏时选择一个独立的50节点卡牌肉鸽模式，可选职业与初始牌组，并保留校园玩法。两个模式需要共享已有战斗体验，同时避免自动成长、回血和奖励互相影响。

入口改为 `GameEntry`，懒加载并仅挂载用户选择的模式。独立远征自己的职业、生命、金币、牌组、遗物与节点状态放在 `features/rogue-mode`，不读取校园角色或背包。战斗复用 `card-battle` 的纯引擎和界面，向其传入冻结的独立属性、卡面和敌人行动循环。校园副本的默认规则保持原调用方式。

远征使用 `lingshu-rogue-run-v1` 独立键，指令带局ID和递增序号，状态机拒绝旧指令。提交时比较完整旧快照，并要求Web Locks串行化写入；缺少该能力时明确拒绝写入，写成功后才更新界面。读取损坏记录不会覆盖；用户确认重开后先备份原始字节，再写新局。奖励选项与随机状态一起保存，重载不能重抽或重复结算。

不引入跨局永久属性、不把远征收益带回校园，也不更改校园存档版本。当前节点类型按每章固定节奏排列，遭遇、奖励与商店遗物按种子随机；分支地图、更多事件和难度阶梯属于后续迭代。未经用户新的上线指令，不发布或递交部署对话。

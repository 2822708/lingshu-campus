# 0006：三选一直接入战与本场自动简历

状态：已采用，2026-10-30。

问题：六项大厅加来源、牌库和简历准备使入场过长。默认八张基础牌又让已学课程和实际装备的卡牌能力很少被体验到。

决定：

- 新大厅固定低、中、高风险各一个可满足学阶的遭遇，选择即进入卡战。精力与学分门槛保留；刷新免费，不改变已建立的战斗。
- 保底八张基础牌，加两张随机战术、最多三张已学课程和三张当前装备。固定种子抽取10–16张，来源池由现有 `sources` 提供，牌值由现有预算与适配器解析。
- 新简历冻结到 `pending.dungeon.entryLoadout`，全局 `cardLoadout` 继续保留玩家旧手配。旧现场没有新字段时继续按旧简历读取。外层存档和互动协议版本不变，新增可选字段由完整性校验覆盖。
- 开局只交换手牌与抽牌堆，保证存在课程、装备来源时各至少展示一张。不增加卡牌或额外抽牌，也不消费新的随机流。
- 同一次入场提交确定自动简历、敌人、费用、牌值和随机现场；存储成功后才显示。原结算继续负责主角色精力、资源和背包奖励。

后果：入口更快，角色的学习和装备直接改变每场可用卡牌。旧手配不丢失；旧未完成战斗和探索可恢复。新现场包含自动简历，较旧客户端不保证能继续读取新现场。暂不增加地图、楼层、跨局遗物或额外成长树。

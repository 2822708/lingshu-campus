# 独立肉鸽模式：远征手记

状态：设计已确定，随后按本文件分阶段实现本地V1。用户已选择50个混合节点，减少重复战斗；没有授权上线或交接。

## 目标与模式入口

启动页先选择“校园成长”或“独立肉鸽”。肉鸽有自己的角色、生命、金币、牌组、遗物及存档，主游戏角色强度不带入，失败不扣主游戏资源。切换模式时卸载另一个模式，避免校园成长的回血、自动操作和存档锁继续运行。

每局：选择职业及初始卡组→遭遇与服务节点→战斗→关卡奖励→调整构筑→十关BOSS→第五章终局。保留3专注、每回合抽4张、保留手牌、结束时超过10张手动弃到10张。正式卡牌高:宽4:3、单行展开、人物与血条分行等要求继续适用。

- [Slay the Spire官方介绍](https://store.steampowered.com/app/646570/Slay_the_Spire/)强调职业牌池、卡牌协同、遗物与不同风险路线。本模式采用职业构筑、精英风险和遗物组合。
- [Monster Train官方介绍](https://store.steampowered.com/app/1102190/Monster_Train/)强调不同初始阵营和沿途升级。本模式让职业与两套开局改变打法，升级和删牌与加牌并列。
- [Wildfrost官网](https://www.wildfrostgame.com/)介绍领袖选择、组合及行动预判。本模式开局给出职业打法，战前预告本章BOSS，战中公开意图。

下述50关安排、奖励数字、跳过奖励、职业名称及卡组配置是本项目设计，不是上述游戏规则的转录。不复制其美术、地图或文案。

## 职业与初始卡组

首版3职业，每职业两套10张初始卡组，可在开始前查看全部卡和职业遗物。

| 职业   | 方向                 | 两种开局           | 起始遗物方向         |
| ------ | -------------------- | ------------------ | -------------------- |
| 锋行者 | 进攻连贯、蓄势、破防 | 均衡强攻／连击蓄势 | 每轮首次进攻追加威力 |
| 守阵者 | 防护、反击、留盾转攻 | 稳守反击／盾势转攻 | 开场防护             |
| 推演师 | 抽牌、破绽、专注调度 | 抽牌准备／破绽爆发 | 开场多抽一张         |

卡池分为职业偏好与通用牌；不引入主角色课程、背包或装备。旧机制可复用，但肉鸽牌值和名称由独立目录定义。每张牌最多升级两次；升级突出该牌原有作用，不将所有牌改成同一种伤害牌。整副牌组控制在8–30张，奖励可跳过，避免被迫把无关卡塞入构筑。

## 50关节奏

五章，每章10节点；第10、20、30、40、50关固定BOSS。每章包含6个战斗节点与4个服务/事件节点，共30场战斗、20个服务或事件。

| 章内关数 | 类型     | 作用                                               |
| -------- | -------- | -------------------------------------------------- |
| 1、2     | 普通战斗 | 建立牌组方向，金币及三选一卡牌                     |
| 3        | 事件     | 稳定资源、生命换收益、整理牌组等明确代价选择       |
| 4        | 精英     | 更强机制，金币、卡牌及遗物选择                     |
| 5        | 休整     | 恢复／升级／删牌，选一项                           |
| 6        | 普通战斗 | 验证前半章的构筑                                   |
| 7        | 商店     | 从治疗、升级、遗物中选择购买或离开，单节点一次交易 |
| 8        | 精英     | 检验机制应对，额外金币与卡牌                       |
| 9        | 休整     | 为BOSS恢复或精炼构筑                               |
| 10       | BOSS     | 独立行动循环、章节成长和遗物选择                   |

三选一战斗遭遇提供不同可预判行动风格，不制作复杂分岔地图。进度条显示本章10节点与后续BOSS机制，玩家随时可查看牌组与遗物。

五章BOSS依次考验：蓄力与防御时机、固守与破防、穿透与进攻节奏、修复与集中爆发、混合循环与资源管理。使用五个专属名称及冻结行动循环；不只换头像或按关数无限加血。

## 关卡奖励与经济

每次胜利的金币与奖励选项同时固定并保存，刷新不重新抽奖；重复确认不重复发放。金币先记入本局，再选择奖励。卡牌三选一均可跳过；精英/章节遗物奖励另选一次，奖励完成后才能进下一节点。

| 节点     | 奖励预算                                                    |
| -------- | ----------------------------------------------------------- |
| 普通胜利 | 约18–30金币，职业倾向三选一卡牌或跳过                       |
| 精英胜利 | 约30–50金币，强化卡牌选择；每章第一精英另给遗物选择         |
| BOSS胜利 | 约65–90金币，稀有倾向卡牌、遗物；生命上限+8，并恢复部分生命 |
| 休整     | 恢复约30%生命／升级一张／移除一张，三选一                   |
| 商店     | 治疗约30金币、升级约50金币、遗物约90金币，按章节缓慢提高    |
| 事件     | 低收益无代价、生命换金币、花金币删牌等透明交换              |

起始金币60。遗物以开场抽牌、首次进攻/防御、防护留存、反击等实际机制影响组合；同名不重复获取。首版至少15个遗物定义，每局携带不超过12个，BOSS/精英共最多10次额外选择。章节成长缓慢提高卡牌与生命预算，敌人同步按节点和类型递增；V1通过固定种子回归和策略抽查调整，不能只凭公式声称平衡。

战斗内治疗沿用本场入场生命上限；休整和章节恢复在父流程执行，下场用恢复后的生命入场。撤离或回合上限视为本局失败，保留失败记录，允许重新开局。

## 模块与存档

新增 `features/rogue-mode/`：类型、职业/卡/遗物/敌人目录、50节点生成与纯状态推进、存档及界面。复用 `features/card-battle` 的纯战斗与反馈，不复用主游戏结算或 `useGameState`。

外层模式壳放在应用入口，一次只挂载一个模式。肉鸽存档使用独立键 `lingshu-rogue-run-v1`；战斗、奖励、商店、休整等动作全部先落盘再显示。保存失败保留操作前现场；旧页覆盖、新旧序号、无效档案均明确拒绝，读取失败不删除原记录。局内牌组、奖励、敌人和随机状态随记录冻结，恢复不重新生成。

共用战斗组件新增可选文案配置，默认仍是原副本；肉鸽显示“生命、牌组、遗物、本局”，不能误称取自主角色。专属BOSS循环须在创建首轮意图前传入并验证，不能战斗创建后偷偷替换。

## 实施与验收顺序

1. **M1 基础闭环**：独立模式壳、3职业×2卡组、独立存档、50关状态和5个BOSS位置。
2. **M2 内容闭环**：普通/精英/BOSS、三选一奖励与跳过、遗物、升级、删牌、休整、事件、商店、失败与通关。
3. **M3 本地验收**：存档往返与异常、连续50节点、三职业真实战斗策略抽查、收益唯一发放、跨模式隔离、桌面和窄矮屏实测、全仓回归及构建；输出实现报告。

本次先完成可玩的本地V1；完整通关链路必须存在，后续版本再增加更多美术、事件与职业。模式不接主游戏资源，不自动上线或交接。

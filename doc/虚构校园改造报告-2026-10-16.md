# 虚构校园改造工作报告

工作日期：2026-10-15 至 2026-10-16。目标：移除游戏对现实学校的指向，保留纸本校园界面、现有玩法和旧存档。

## 改造结果

产品统一为《灵枢录 · 校园成长记》，背景是一所虚构的工科学园，不另外使用专有校名。标题、首页、登记、档案、导航、设置、网页元信息和包说明均采用新设定。

| 原设定类型 | 当前替代 |
|---|---|
| 现实大学与校园身份 | 虚构工科学园、学园同学 |
| 八个现实院系组织 | 电路、信号、算法、网络、光电、物联、材料、自控学部 |
| 专有校区地标 | 东区、西区及通用校园场景 |
| 学校口号 | 一页日常，一点成长；学习 · 实践 · 记录 · 成长 |
| 现实机构、期刊和竞赛背书 | 学园研习室、校内比赛与虚构学术活动 |

通用工程术语、课程内容和技术名称保留。品牌与生成背景集中在 `config/campusTheme.ts`，本轮没有更改纸色、墨绿、档案和手记的界面布局。

## 存档与生成兼容

`utils/campusText.ts` 在展示时转换已知旧文案。手记、背包、装备、商店、社团物品、批量丢弃、强化、室友喂食、通知和丢弃确认框均接入。缺失描述按空文本显示；正常的“NPU 推理芯片”等技术语境不作校名替换。

原始日志、物品业务名称、配方键、玩家自定义姓名、UID、存储键、`npu:` 天赋 ID、存档版本与枚举保持原样。因此，导出旧存档仍可包含其原始文字；显示适配不承担删除用户数据的职责。重新读取旧天赋 ID 会解析到当前学部文案。

三类 AI 请求（校园事件、升学文字、对手名称）均加入虚构背景约束，并只对返回的故事、物品名与描述、对手名称与称号进行文本适配。数值、ID、奖励结构和配方键不做整体字符串替换。AI 真实服务本轮未调用，使用模拟响应验证请求约束和结果边界；未知现实名称的生成仍受模型行为影响，不能把有限词表视为完整内容审查。

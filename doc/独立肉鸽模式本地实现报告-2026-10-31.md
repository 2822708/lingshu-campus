# 独立肉鸽模式本地实现报告

日期：2026-10-31。范围：本地V1，未上传、部署或递交上线对话。策划先行，完整方案见[设计文档](独立肉鸽模式策划与实施方案-2026-10-30.md)。

## 已形成的玩家流程

启动后选择“校园成长”或“独立肉鸽”。远征可选锋行者、守阵者、推演师，每个职业有两套10张初始牌组及专属起始遗物。既有远征可以继续，新开局覆盖前需要确认。两个模式互斥挂载，远征不读取校园角色、背包或金币。

一局50个混合节点，包含15场普通战斗、10场精英、5场BOSS、5个事件、5个商店和10次休整。每章节点依次为“遭遇、遭遇、事件、精英、休整、遭遇、商店、精英、休整、BOSS”。节点类型节奏固定，普通/精英的三个敌人选择、卡牌奖励和商店遗物按种子生成并冻结，不是自由分岔地图。

| 系统     | V1实际内容                                                                               |
| -------- | ---------------------------------------------------------------------------------------- |
| 卡牌     | 34张独立定义，职业倾向奖励；基础攻防、抽牌、蓄势、破绽、恢复专注、反击、留盾和转攻等机制 |
| 遗物     | 18件，最多携带12件，同名不重复；开场/每轮/首次进攻防守等时机生效                         |
| 战斗     | 共用正式卡战纯内核与反馈，每轮3专注、抽4张、手牌保留，回合结束超过10张先手动弃牌         |
| 普通胜利 | 金币与卡牌三选一，可跳过选牌                                                             |
| 精英胜利 | 较高金币与选牌；每章第一场精英额外三选一遗物                                             |
| BOSS胜利 | 金币、稀有倾向选牌、遗物、生命上限+8及章节恢复；遗物满位时相应奖励折算30金币             |
| 休整     | 恢复30%生命、升级一张牌、移除一张牌，三选一                                              |
| 商店     | 治疗、升级、购买本节点固定遗物或离开，每节点一次交易；成本与章节挂钩                     |
| 事件     | 稳定金币、损失8生命换更多金币、支付15金币删牌；选择前显示实际代价                        |
| 结局     | 战败、撤离或26轮僵持结束本局；第50关结算后展示五位BOSS记录和重开入口                     |

第10/20/30/40/50关依次为钟塔守望、镜甲司书、裂隙游猎者、回响缝合者、终页裁决者。分别运用蓄力、防护反震、穿透、修复窗口与混合循环，首轮就使用专属行动，后续循环随存档保留。

## 模块和数据边界

`GameEntry.tsx`负责模式选择；`features/rogue-mode`集中职业目录、节点状态机、持久化和页面。正式校园副本继续调用原有 `card-dungeon`。共用 `CardBattleView` 的新增模式参数有默认值，独立远征显示“生命、牌组、遗物、本局”，校园副本保持课程与装备来源展示。详情见[ADR 0007](adr/0007-independent-rogue-mode.md)。

独立键为 `lingshu-rogue-run-v1`。战斗、奖励、商店、事件和休整均先保存后展示，保存失败不扣钱、不治疗、不增牌、不前进。指令校验局ID和递增序号，提交比较完整前态，写入由浏览器Web Locks串行化。读取损坏档不会删除或覆盖；确认重开时必须先备份原始字节。奖励选项、敌人和随机状态持久化，刷新续接不重抽、不重复发金币。单份远征记录限制为2MiB。

主游戏存档版本和键保持原样。远征没有跨局永久属性、主游戏奖励回流、真实模型请求或新后端接口。

## 数值抽查与后续优先级

基础参数抽查3职业×2卡组×12种子，共72局、2160场真实引擎战斗。可见信息策略跳过全部卡牌奖励仍72局通关，平均战斗2.37轮、每战净损生命4.62，最终余金约1103。说明当前V1偏宽松、初始牌组完成度较高，后期商店消耗不足；通关检查不等于游戏已平衡。

另作三组临时参数实验，各使用两种简单选牌策略和3个种子，共108局，未改业务源代码：

| 临时敌人倍率（生命/攻击） | 全跳过选牌通关 | 简单选牌至16张通关 |
| ------------------------- | -------------- | ------------------ |
| 1.25 / 1.25               | 15/18          | 18/18              |
| 1.40 / 1.30               | 15/18          | 15/18              |
| 1.25 / 1.40               | 15/18          | 15/18              |

三组同时把商店遗物改为150/170/190/210/230金币，因此不能把结果单独归因于敌人倍率。失败主要集中推演师“抽牌准备”，可见策略也存在准备牌费用规划不足，不能据此判断职业必败。首版保留基础参数，将1.25/1.25作为下轮候选；先补更多种子与推演师手动试玩，再分别调整职业和经济，避免统一加难掩盖问题。

下一步按顺序：校准各职业初始牌的投入产出；改善事件与商店的资源取舍；针对BOSS强化构筑检验。分支地图、跨局解锁和更多模式暂不加入，保持当前操作规模。
